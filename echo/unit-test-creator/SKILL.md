# Context

This is a Go carpooling REST API. Module name: **`api`** (all imports start with `api/internal/...` or `api/pkg/...`).

Stack: **Echo v5 · GORM + PostgreSQL · Clean Architecture**

```
internal/
  models/           → GORM structs + BeforeCreate hooks (UID auto-generation)
  models/tests/     → model-layer unit tests (SQLite in-memory)
  usecase/
    client/         → OTPUsecase, UserUsecase, ProfileUsecase, TripUsecase, ExploreUsecase, BookingUsecase
    admin/          → AdminUsecase, UserUsecase, TripUsecase, BookingUsecase
  repository/
    client/         → DB interfaces (OTPRepository, UserRepository, …)
    admin/          → DB interfaces (AdminRepository, UserRepository, …)

pkg/
  auth/             → CreateToken / ValidateToken (HS256 JWT)
  request/          → AppError, NewAppError, ErrorResponse, NewPagination, GetPaginationParams
  middlewares/      → AuthMiddleware, AdminAuthMiddleware, CheckUserStatusMiddleware
  testutils/        → SetupTestDB (in-memory SQLite via gorm.io/driver/sqlite)
```

# Three Kinds of Unit Tests

## 1 · Model Layer Tests  (`internal/models/tests/`)

Test GORM model behaviour directly against an in-memory SQLite DB.

### File layout
```
internal/models/tests/<model_name>_test.go
```
Package: `package tests`

### DB setup — always use `testutils.SetupTestDB`
```go
db := testutils.SetupTestDB(t,
    &models.User{},
    &models.Profile{},
    &models.Trip{},   // pass every model the test touches
)
```
`SetupTestDB` opens `:memory:` SQLite and calls `AutoMigrate` on the given models.

### What to test
| Area | Test cases |
|---|---|
| **Create** | Record persists; `ID > 0`; `UID` non-empty (auto-generated by `BeforeCreate`) |
| **Read** | By ID / by unique field; with `Preload` for relations |
| **Update** | Field changes persist; status transitions |
| **Delete / soft-delete** | Hard delete removes row; status-based soft delete (e.g. `UserStatusDeleted`) |
| **Constraints** | GORM hooks validate domain rules (e.g. motor max 1 passenger, car max 3) |
| **Enum constants** | Assert every constant equals its string literal value |

### Template
```go
package tests

import (
    "testing"
    "api/internal/models"
    "api/pkg/testutils"
    "github.com/stretchr/testify/assert"
)

func TestBookingModel(t *testing.T) {
    db := testutils.SetupTestDB(t, &models.User{}, &models.Trip{}, &models.Booking{})

    // shared fixtures
    user := &models.User{PhoneNumber: "09120000001", Status: models.UserStatusActive}
    db.Create(user)

    t.Run("Create", func(t *testing.T) {
        b := &models.Booking{UserID: user.ID, /*…*/}
        assert.NoError(t, db.Create(b).Error)
        assert.NotZero(t, b.ID)
        assert.NotEmpty(t, b.UID)
    })

    t.Run("Read with relations", func(t *testing.T) { /* … */ })
    t.Run("Update status", func(t *testing.T) { /* … */ })
    t.Run("Delete", func(t *testing.T) { /* … */ })
    t.Run("Status constants", func(t *testing.T) { /* … */ })
}
```

## 2 · Usecase Layer Tests  (`internal/usecase/<client|admin>/tests/`)

Test business logic in isolation — **no real DB, no Redis, no HTTP**.  
Inject fake (hand-written) repository implementations.

### File layout
```
internal/usecase/client/tests/<feature>_usecase_test.go
internal/usecase/admin/tests/<feature>_usecase_test.go
```
Package: `package tests`

### Fake repository pattern
Implement only the methods your test exercises. Use a struct with result fields:

```go
type fakeOTPRepo struct {
    otp *models.OTP
    err error
}

func (f *fakeOTPRepo) Create(_ context.Context, otp *models.OTP) error {
    f.otp = otp
    return f.err
}
func (f *fakeOTPRepo) GetByPhoneNumber(_ context.Context, _ string) (*models.OTP, error) {
    return f.otp, f.err
}
func (f *fakeOTPRepo) Delete(_ context.Context, _ *models.OTP) error { return f.err }
```

Wire into the usecase under test:
```go
uc := client.NewOTPUsecase(&fakeOTPRepo{}, nil) // nil = no Kavenegar in test
```

### What to test
| Scenario | Assert |
|---|---|
| **Happy path** | Returns expected value; no error |
| **Repository error** | Returns wrapped `AppError` with correct numeric code |
| **Business rule violation** | Returns `AppError` with correct code (e.g. trip capacity, duplicate booking) |
| **State transition** | Input model field mutations are correct before repo call |
| **Conditional branches** | e.g. `rememberMe` extends JWT TTL; `Debug=true` skips SMS |

### Asserting AppError codes
```go
import "api/pkg/request"
import "errors"

var appErr *request.AppError
require.True(t, errors.As(err, &appErr))
assert.Equal(t, 3004, appErr.Code) // already booked
```

### Config initialisation
Some usecases (e.g. OTPUsecase) read `config.AppConfig`:
```go
func init() {
    if config.AppConfig == nil {
        config.AppConfig = &config.Config{}
    }
    config.AppConfig.Debug = true  // skips SMS sending
    config.AppConfig.JWTSecret = "unit-test-secret"
}
```

### Template
```go
package tests

import (
    "context"
    "errors"
    "testing"

    "api/config"
    "api/internal/models"
    "api/internal/repository/client"
    clientuc "api/internal/usecase/client"
    "api/pkg/request"

    "github.com/stretchr/testify/assert"
    "github.com/stretchr/testify/require"
)

func init() {
    if config.AppConfig == nil { config.AppConfig = &config.Config{} }
    config.AppConfig.Debug = true
    config.AppConfig.JWTSecret = "unit-test-secret"
}

// ── fakes ─────────────────────────────────────────────────────────────────

type fakeOTPRepo struct {
    otp *models.OTP
    err error
}
func (f *fakeOTPRepo) Create(_ context.Context, otp *models.OTP) error  { f.otp = otp; return f.err }
func (f *fakeOTPRepo) GetByPhoneNumber(_ context.Context, _ string) (*models.OTP, error) { return f.otp, f.err }
func (f *fakeOTPRepo) Delete(_ context.Context, _ *models.OTP) error    { return f.err }

// ── tests ─────────────────────────────────────────────────────────────────

func TestRequestOTP(t *testing.T) {
    t.Run("creates OTP and returns code in debug mode", func(t *testing.T) {
        repo := &fakeOTPRepo{}
        uc := clientuc.NewOTPUsecase(repo, nil)
        code, err := uc.RequestOTP(context.Background(), "09120000001")
        require.NoError(t, err)
        assert.Len(t, code, 5)
        assert.NotNil(t, repo.otp)
        assert.Equal(t, "09120000001", repo.otp.PhoneNumber)
    })

    t.Run("returns AppError 1004 when repo.Create fails", func(t *testing.T) {
        repo := &fakeOTPRepo{err: errors.New("db down")}
        uc := clientuc.NewOTPUsecase(repo, nil)
        _, err := uc.RequestOTP(context.Background(), "09120000001")
        require.Error(t, err)
        var appErr *request.AppError
        require.True(t, errors.As(err, &appErr))
        assert.Equal(t, 1004, appErr.Code)
    })
}
```

## 3 · Pkg Layer Tests  (`pkg/<package>/`)

Test pure utility functions — no DB, no HTTP, no mocks needed.

### File layout
```
pkg/auth/jwt_test.go
pkg/request/errors_test.go
pkg/request/pagination_test.go
```
Package: `package <pkg>` (white-box, same package as the file under test).

### What to test per package

| Package | Key test targets |
|---|---|
| `pkg/auth` | `CreateToken` → valid JWT, correct claims; `ValidateToken` → extracts claims, rejects tampered token, returns `ErrExpiredToken` for expired token |
| `pkg/request` | `NewAppError` → implements `error`, unwraps code; `NewPagination` → correct `TotalPages` math; `GetPaginationParams` → defaults when absent |
| `pkg/middlewares` | `AuthMiddleware` / `AdminAuthMiddleware` → unit-test with `httptest.NewRequest` + Echo context (no real Redis) |

### Template — `pkg/auth`
```go
package auth

import (
    "testing"
    "api/config"
    "github.com/stretchr/testify/assert"
    "github.com/stretchr/testify/require"
)

func init() {
    if config.AppConfig == nil { config.AppConfig = &config.Config{} }
    config.AppConfig.JWTSecret = "unit-test-secret"
}

func TestCreateAndValidateToken(t *testing.T) {
    t.Run("round-trip: create then validate", func(t *testing.T) {
        tok, err := CreateToken(42, "01TESTUID0000000000000000001", "", false)
        require.NoError(t, err)
        claims, err := ValidateToken(tok)
        require.NoError(t, err)
        assert.Equal(t, uint(42), claims.UserID)
        assert.Equal(t, "01TESTUID0000000000000000001", claims.UID)
    })

    t.Run("tampered token returns ErrInvalidToken", func(t *testing.T) {
        _, err := ValidateToken("not.a.token")
        assert.ErrorIs(t, err, ErrInvalidToken)
    })
}
```

### Template — `pkg/request` pagination
```go
package request

import (
    "testing"
    "github.com/stretchr/testify/assert"
)

func TestNewPagination(t *testing.T) {
    t.Run("calculates total pages correctly", func(t *testing.T) {
        p := NewPagination(25, 1, 10)
        assert.Equal(t, 3, p.TotalPages)
        assert.Equal(t, int64(25), p.Total)
        assert.Equal(t, 1, p.Page)
        assert.Equal(t, 10, p.Limit)
    })

    t.Run("enforces minimum page=1 and limit=10", func(t *testing.T) {
        p := NewPagination(5, 0, 0)
        assert.Equal(t, 1, p.Page)
        assert.Equal(t, 10, p.Limit)
    })

    t.Run("caps limit at 100", func(t *testing.T) {
        p := NewPagination(1000, 1, 500)
        assert.Equal(t, 100, p.Limit)
    })
}
```

# General Rules

- **No real DB in usecase tests** — fake the repository interface entirely.
- **No real DB in pkg tests** — these are pure functions.
- **SQLite only for model tests** — `testutils.SetupTestDB` is the only allowed DB in tests.
- **Never use `AutoMigrate` outside `testutils`** — production uses `gormigrate`.
- **Module name is `api`** — all imports: `api/internal/...`, `api/pkg/...`.
- **UIDs are ULIDs** — `BeforeCreate` auto-generates them; assert `NotEmpty`, never hardcode a specific value.
- **Use `t.Run` subtests** — always; never write a flat test with multiple `assert` blocks testing different scenarios.
- **Table-driven tests** — preferred for pure functions with multiple input/output combos.
- **`errors.As` for AppError** — never cast directly; always `errors.As(err, &appErr)`.
- **`assert` vs `require`** — use `require` when failure makes subsequent lines invalid (e.g. `require.NoError` before dereferencing a pointer).

---

# Workflow

1. **Identify the layer**: model, usecase, or pkg?
2. **Read the source file** before writing any test.
3. **Model test** → `internal/models/tests/<model>_test.go`, package `tests`, use `testutils.SetupTestDB`.
4. **Usecase test** → `internal/usecase/<client|admin>/tests/<feature>_usecase_test.go`, package `tests`, write fake repos.
5. **Pkg test** → `pkg/<package>/<file>_test.go`, same package as source.
6. **Run** `go test ./...` and confirm all pass — fix any compilation or assertion errors before finishing.

# Run Commands

```bash
# All unit tests
go test ./internal/models/tests/...
go test ./internal/usecase/...
go test ./pkg/...

# Single package
go test ./internal/usecase/client/tests/... -v

# Single test by name
go test ./pkg/auth/... -run TestCreateAndValidateToken -v

# All tests
go test ./...
```
